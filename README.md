# FramePicker

iPhoneの画面収録またはMac上の動画から、UI確認に必要なフレームを選び、連番PNGとしてまとめて書き出すmacOSアプリです。

## 現在の機能

- iCloud写真に同期された最新のiPhone画面収録を取得
- 右上の「Macの最新動画」で、デスクトップ・ムービー・ダウンロード直下の最新動画を自動取得
- 「Finderで選択」、またはドラッグ＆ドロップで任意のMac上の動画を入力
- 読み込み後は確認付きのリセットボタンで、動画と現在の選択状態を閉じる
- アプリを終了しても最後の動画、出力予定の選択フレーム、下部で選んでいた位置を保持し、次回起動時に自動復元
- 動画下部に、実フレームの連続フィルムストリップを自動生成
- フィルムストリップの密度を8 / 12 / 24 / 48 fpsで切り替え（初期値は8 fps）
- フレームをクリックすると、その実フレームで動画を自動停止
- 動画の再生・停止位置に合わせて、フィルムストリップの青枠と表示位置を同期
- 左右の矢印キーで、フィルムストリップ上のフレームを前後に移動
- 確定フレームを左側へ追加し、元動画の縦横比でサムネイル表示
- 選択サムネイルにホバーした時だけ、上へ移動・単体コピー・削除・下へ移動を画像上に表示
- 選択フレームの並べ替え、削除、動画ごとの選択状態の復元
- PNG書き出し隣のコピーアイコンは、左側に表示中の出力予定フレームをすべてコピー
- ⌘C／Ctrl+Cは、左側で青枠選択しているフレームをコピー。左側が未選択なら下部フィルムストリップの青枠位置から元動画の解像度で再抽出してコピー
- 単体コピーは元解像度のPNG、複数コピーは左側の並び順を保った連番PNGとしてクリップボードへ追加。複数ファイル対応の貼り付け先で12枚すべてを受け取れる（FigmaのFrameへ変換しない）
- コピー処理中のスピナーはコピーボタン内に表示
- コピー成功時は「コピーしました」を短時間表示
- 左側の選択サムネイルをクリックすると、下部フィルムストリップと同じ3pxの青枠を表示し、動画も同じフレームへ移動
- 左側の選択サムネイルはShift＋クリックで複数選択・選択解除
- Clean Apertureを使い、動画の実ピクセル領域を黒帯なしでPNG化
- 保存先の初期表示はデスクトップ。`001.png`から始まる連番PNGを`framepicker-YYYYMMDD`フォルダへ一括出力
- 「選択中」「動画履歴」を切り替え可能。動画履歴には代表サムネイルと選択枚数が並び、動画と選択フレームを開き直せる
- サムネイルを保存していない古い動画履歴には、代わりに最終操作日時を表示

## ビルド

```sh
git clone https://github.com/0kamura/FramePicker.git
cd FramePicker
zsh scripts/build-app.sh
open dist/FramePicker.app
```

初回にiPhoneの画面収録を開くときは、macOSの写真アクセス確認で許可してください。
ビルドでは固定の指定要件を使って署名するため、初回許可後は再ビルドしても同じ写真アクセス権を引き継ぎます。
